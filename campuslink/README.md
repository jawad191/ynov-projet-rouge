# CampusLink

CampusLink est une interface web statique permettant de consulter et de gérer les salles, les équipements et les incidents d'un campus.

## Objectif

Ce projet correspond à la première version de l'interface de CampusLink.  
L'objectif est de créer une interface claire, responsive et accessible en utilisant uniquement HTML et CSS.

## Pages réalisées

- Tableau de bord
- Salles
- Équipements
- Incidents
- Détail d'un incident
- Déclaration d'un incident

## Technologies utilisées

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design

## Structure du projet

CampusLink/
├── index.html
├── salles.html
├── equipements.html
├── incidents.html
├── incident-detail.html
├── declarer-incident.html
└── css/
    └── style.css

## Fonctionnalités:
Navigation entre les différentes pages
Consultation des salles et des équipements
Consultation des incidents
Affichage du détail d'un incident
Formulaire de déclaration d'un incident
Adaptation de l'interface aux écrans mobiles et desktop
Navigation au clavier

## Installation:

. Aucune installation particulière n'est nécessaire.

. Ouvrir simplement index.html dans un navigateur web.
